# 坡地弓手 · 一箭过山河

中文像素弓箭游戏：三章故事、同机双人、电脑对手、肉鸽远征和射靶挑战。原生 JavaScript + Canvas，可直接本机游玩；可选账号用于云存档，无需模型 API。

**[在线游玩](https://hillside-archers-first-duel.soundhorse9.chatgpt.site)** · **[免费备用站](https://shengjunqi.github.io/hillside-archers/)** · [合作开发](CONTRIBUTING.md) · [给合作作者的 Codex 提示词](docs/CODEX_COLLABORATOR_PROMPT.md) · [MIT 许可证](LICENSE)

## 运行

手机和电脑使用同一个在线链接。顶部「自动 ▾」可选择自动识别、电脑版或手机版，浏览器会记住选择；切换保留当前对局与进度。手机支持横屏和竖屏，不需要安装应用。

免费的 GitHub Pages 备用入口已启用，由独立 `gh-pages` 分支发布。启用步骤、访问范围及离线分享见 [发布说明](docs/DEPLOYMENT.md)。不同网址可通过旅营「迁移进度」复制永久存档。

本地开发需要 Node.js 22+。项目没有 npm 安装依赖；可选在线功能使用已附许可证的 CloudBase SDK。

```sh
git clone https://github.com/ShengJunqi/hillside-archers.git
cd hillside-archers
npm run dev
```

打开 **http://127.0.0.1:8080**。也可以下载 `dist/download.html`，直接用浏览器打开离线游玩。

```sh
npm test        # 语法与游戏逻辑检查
npm run build   # 重新生成单文件离线版
```

## 已有玩法

- 三张不同地形的地图、整数角度、拖拽蓄力和可取消射击。
- 玩家回合先展示对手，再回到自己；电脑轮到直接射箭。同机双人保留双方观察，箭飞行时镜头跟随。
- 瞄准时轻点画面，角色会跳跃或秀肌肉；拖拽继续控制拉弓。
- 旅营/暂停菜单可设置两位弓手的名字，应用于血条、剧情和结算，并随迁移码保存。
- 木箱可打碎、木桩可击倒；头、身体、腿、脚有不同伤害。
- NPC 追加箭分散、同轮连续爆头衰减，并有单轮伤害上限；守关敌人保留双箭、属性与更高耐久。
- 四肢分别受力：击退、踉跄、翻倒与起身；插入的箭跟随肢体，倒地不跳过回合。
- 角色初始天赋、弓术、远征遗物分别记录，方便继续扩展角色。现有弓手具有一次危急回息。
- 开局没有道具；主线第三章交锋后开始生成。穿过 `+1` 连续加箭，爱心回血。
- 三章通关或主动跳过新手教程后，解锁自由人机、同机双人、无尽远征、百步穿杨。
- 远征有三种空中二段弓术、12 类遗物、五种属性组合、守关敌人与永久成长。
- 火、毒重复升级提高每次命中的叠层，连续命中继续累加；升级卡显示前后效果，战斗显示层数和剩余回合。
- 第七层后敌人开始组合多种属性，深层守关者有多箭、续航与部分净化；保留 NPC 单轮伤害保护。
- 新手首战对手半血，剧情与观察节奏更快；可直接跳过教程解锁玩法，不额外发放奖励。
- 主线进度、解锁、纪录和永久成长保存在当前浏览器；可选账号登录同步永久进度。当前远征的临时构筑不跨重开保留。

## 操作

手机：按住画面向弓手身后拉，松开射箭；拉回圆圈或点“取消拉弓”撤销。也可点 − / ＋ 微调整数角度，再点“射箭”。观察镜头可点“开始本回合”跳过。支持屏幕旋转、安全区与全屏／沉浸模式。

电脑：拖拽向弓手身后拉弓，松手射箭。拉回取消圈、右键或 Esc 取消蓄力。左右键微调整数角度；空格射箭或跳过观察镜头。远征中，箭飞行时再按空格或点击画面触发弓术。

## 文件结构

| 文件 | 职责 |
| --- | --- |
| `dist/core.mjs` | 物理、碰撞、状态机、AI、升级与存档 |
| `dist/combat.mjs` | NPC 强度配置、角色定义与初始天赋 |
| `dist/body.mjs` | 四肢关节约束、冲击、恢复与移动部位碰撞 |
| `dist/render.mjs` | 地图、角色、镜头、粒子和剧情动画 |
| `dist/app.mjs` | UI、屏幕适配、音效与浏览器存储 |
| `dist/input.mjs` | 鼠标、触屏、取消蓄力和多指保护 |
| `dist/display.mjs` | 自动识别、手动切换布局与独立显示偏好 |
| `dist/names.mjs` | 默认/自定义显示名字、校验与剧情替换 |
| `dist/save-transfer.mjs` | 不同网址间的永久进度导出与合并 |
| `dist/index.html` / `dist/style.css` / `dist/mobile.css` | 页面结构、桌面样式与手机布局 |
| `dist/download.html` | 构建生成的单文件离线版 |
| `tests/` | 可移植的 Node 逻辑与回归检查 |
| `scripts/` | 本地服务器与离线版生成工具 |

`dist/` 同时是可维护源码和部署目录，尚未拆分为单独的 `src/`。详细规则和数值见 [游戏设计说明](docs/GAME_DESIGN.md)。

旅营／暂停菜单提供可选「账号与云存档」：账号密码登录、邮箱验证注册和联系管理员找回密码。首次关联和设备冲突时明确选择进度；余烬与修行等级整组保存，不相加余额。离线版继续使用本机存档和迁移码。云端配置与验收见 [账号存档说明](docs/ACCOUNT_SAVES.md)、[CloudBase 接入记录](docs/CLOUDBASE_SETUP.md)。

## 一起开发

请先读 [AGENTS.md](AGENTS.md) 与 [CONTRIBUTING.md](CONTRIBUTING.md)，使用独立分支和 PR 协作。一位作者可以主要负责规则和物理，另一位主要负责地图、角色、动画和 UI。

GitHub 推送**不会自动更新现有游玩链接**。线上发布由维护者统一执行；本仓库不包含部署账号或凭证。任何静态托管服务都可以托管 `dist/`，不需要服务端程序。
