# 可以直接复制给合作创作者的 Codex

下面整段直接发送即可。最后的任务示例可以替换成你们当次分工。

---

你是《坡地弓手 · 一箭过山河》的合作开发者，请在已有游戏上增量开发。

仓库：https://github.com/ShengJunqi/hillside-archers

当前游玩链接：https://hillside-archers-first-duel.soundhorse9.chatgpt.site

先读取 AGENTS.md、README.md、CONTRIBUTING.md 和 docs/GAME_DESIGN.md，检查工作区和分支，运行 npm test、npm run build，再用 npm run dev 启动。已有检出就使用它，没有才 clone。Node.js 要求 22+，没有 npm 依赖。

这个项目使用原生 JavaScript 和 Canvas。dist/core.mjs 管规则、物理、AI、升级、存档；dist/combat.mjs 管 NPC 伤害预算和角色初始天赋；dist/body.mjs 管四肢受力、倒地恢复和移动碰撞；dist/render.mjs 管地图、角色和镜头动画；dist/input.mjs 管鼠标和触屏输入；dist/display.mjs 管显示模式与偏好；dist/app.mjs 管 UI、屏幕适配和音效；dist/index.html、dist/style.css 与 dist/mobile.css 管页面及横竖屏布局。dist/download.html 是生成文件，请通过 npm run build 更新。同一个网址支持「自动识别 / 电脑版 / 手机版」切换，手动选择优先，切换不能重开对局、丢存档或误射。

我们有两位作者。先从最新 main 建立独立功能分支；不覆盖未提交改动，不直接推 main，不擅自合并或发布线上网站。完成后开 PR，若没有仓库写权限就走 fork + PR，并给出 PR 链接。

保留这些要求：角度只用整数；不要游戏下方的参数面板；玩家回合先看对手再回自己，电脑对手直接出箭；拉回取消圈、右键、Esc 可以取消蓄力；开局没有道具球；主线前两章没有道具，第三章在回合结束后生成；+1 能连续叠加；三章通关或主动跳过新手教程可解锁其他模式；保留同机双人、肉鸽三种弓术、12 类遗物、五种组合和现有存档。

可以参考 Bowmasters 的一般玩法机制，但美术、角色、动画和代码保持原创。不要改造成需要付费 API 或服务器的游戏。

本次分工：优先优化地图、角色动作和剧情动画，让三个关卡的视觉区别与开场、胜利、失败演出更明显。主要修改 render.mjs、style.css 和必要的 UI 文案，保持物理、伤害、解锁规则不变。先确认现有实现，再完成一组范围明确、能审查的改进，不要整站重写。

提交前运行测试和离线构建，尽可能进行真实浏览器操作验证。没有浏览器工具时明确说明，不要声称已经点测。最后用中文说明改动、测试、未验证部分，以及需要另一位作者配合的地方。

新增角色请先读 docs/CHARACTERS.md，保留初始天赋、弓术、远征额外遗物的独立状态。NPC 连续穿 +1 的多箭、爆头、元素和持续伤害都必须经过单轮预算；玩家的多箭不受限。守关者可以强，但应保留反击机会。

火毒天赋阶数、目标状态层数和持续回合必须分开显示与结算，不能恢复旧4/5层的小上限。冰霜满3阶后不再提供。后期敌人组合与耐久从第7层起加强，首战半血及前六层友好强度要保留。两个网址由 Sites 与 gh-pages 分支分别部署，旅营支持进度代码迁移，详见 docs/DEPLOYMENT.md。

保留旅营/暂停的自定义名字设置，显示名字与角色ID/技能分开。旧v2存档无names字段时正常使用默认名；HA2对中文名字采用JSON转义。跳过新手教程会永久解锁玩法，但不伪造通关奖励或覆盖原检查点。
