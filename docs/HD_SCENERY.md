# 0.15.0 高清场景与风格选择

用户反馈旧地图和背景仍然简陋，本轮将少量多边形拼成的远景替换为完整绘景，提供五种真正不同的画面方向：晴空手绘、落日厚涂、月夜奇幻、纸雕舞台、暖灯港湾。默认「随赛场变化」，也可固定喜欢的风格。

## 玩家入口

主页或暂停菜单 → **场景风格** → 点选图片。选择即时应用并保存在本机，不更改当前回合、角度、站位、NPC 强度或存档；进入游戏后可随时更换。设置页支持手机横竖屏滚动、键盘 Tab／Esc，账号／迁移／改名弹窗互斥。

自动模式下，主线三张地图分别使用山林、峡谷和月夜遗迹；无尽的码头、夜市、领奖台与碗底场地使用港湾；路牌场使用纸雕，其余跟随地貌色系。原八种无尽模板的坡形、距离、掩体和选路保持独立，不因换风格而重置或重算。

## 素材与绘制

五张背景原尺寸为 1672×941，另有 1254×1254 土岩材质。发布只做 WebP 编码，不放大冒充更高原始分辨率。素材与尺寸见 [资源来源](../dist/art/SOURCES.md)。全部图片和字体由本站提供，离线 HTML 内嵌同样的资源。

- 移除 CSS 的像素化缩放，背景绘图开启平滑与 high 质量；保留原逻辑世界与触控坐标，避免仅增加 Canvas 像素导致角度、镜头和输入错位。
- 高清素材就绪后替换旧 skyline／venue 大块几何，避免把新图遮住。天空有向上延展与边缘渐隐，高抛仍能看见完整背景。
- 背景随镜头轻微错层移动；地面用真实 `ground(x, game.world)` 路径裁切土岩材质，保留连续表层草边、岩层明暗和少量碎石。
- 图片异步载入，不设置开局等待。加载失败继续程序绘图，游戏仍可玩；资源到达和风格改变会更新缓存。
- 专用资源缓存最多保留当前背景和地面纹理两张解码图，地形与背景合成层缓存复用。风格选择页的缩略图按需加载，不在游戏循环里创建 DOM。
- 风格偏好使用独立 `hillside-archers-scenery-v1`，不加入 v2 永久存档、HA2 或云存档。

## 验证与限制

执行完整规则／账号／输入测试及离线构建；新增图片 pending／ready／失败／异常、LRU 上限、晚到资源与风格缓存、真实地面裁切、碰撞不变、高抛天空覆盖等检查。通过原生 Canvas 实际导出五张游戏场景和手机竖屏图；这些不是浏览器截图。

当前环境未提供可调用的浏览器控制入口，未启动替代预览或安装替代浏览器。真实浏览器布局、手机 GPU 帧率及弱网加载时长仍待玩家实测。图片晚到／失败的 Node 回归不等同于手机性能验证。
