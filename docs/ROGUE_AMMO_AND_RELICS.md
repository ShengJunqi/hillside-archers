# 0.18.0 特箭弹药与隔关强化

无尽的特殊能力由“每轮随时用一次”改为有限弹药；普通箭仍可无限射击。这里的特箭指散羽、星坠、引爆三种弓术，火／冰／毒等已获得的附魔仍随普通箭生效。

## 弹药是整轮弓术的资源

- 新远征携带2份弹药，每进入一个新关补1份，最多储存5份；剩余弹药可跨关保留。
- 每次成功施展弓术扣1份，作用于本轮飞箭；多箭、分裂、穿过+1不重复收费。开预瞄、改方向、取消、失焦和暂停均不扣弹。
- 用完后仍能射普通箭。无弹药时箭上不显示未用炸弹；战斗中回收到弹药后可重新使用弓术。每轮仍最多施展一次。
- 补弹只在真正推进新关时执行，重绘、重复setup或重复点继续不会刷弹。重开远征回到2份，回营不会把临时弹药写入永久存档。

HUD、武器选择和暂停页说明余量与规则。少量特殊箭由玩家选择时机，保留多箭构筑的整轮收益，不按每支追加箭重复扣费。

## 每两关选一次更有分量的强化

每关胜利后都可选路线、休息和补弹；第1、3、5关之后直接出发，第2、4、6关之后再选一项强化。重选次数可保留到有强化的关卡，奇数关不能通过重选绕过奖励节奏。每关仍休息回复12，三关守关后额外回复25；不因为奇数关没有强化而丢掉守关休息。

| 强化 | 本次选择的效果 |
| --- | --- |
| 鹰眼 | 直接伤害系数+0.40，原来每次+0.20 |
| 焰羽／青毒 | 增加2阶，原来每次1阶 |
| 长青 | 最大生命+40并回复40，过关休息另算 |
| 猎隼 | 暴击率+20个百分点，上限75% |
| 饮露 | 吸血比例+18个百分点，上限60% |
| 破阵 | 穿障+1，最多3阶；每关击破掩体可回收1份弹药，最多一次 |
| 分弦／霜弦 | 保留+1箭／+1阶冰的作用和原上限 |

新的奖励池共12项。震弦、扎根、星泉、回春、铁衣移出新奖励池，保留旧ID与运算兼容；不再让这些较弱位移、抗性或慢回血选项占据稀少的强化机会。基础能力和NPC强度规则没有提高。`applyUpgrade`保留旧基础阶数运算；隔关奖励通过`relics.applyRewardUpgrade`使用表中增量，卡片预览与实际奖励使用同一纯函数。

## 三种新增强化

**回声落羽**：每轮首次实体箭命中后，从对手上方召来追击箭，一至三阶分别1／2／3支，每支45%直接伤害，并继承已获得的元素。落羽按真实关节和击退速度有限修正方向，目标被推开后仍可追击，保持实际飞行与掩体碰撞。落羽及其追加箭不会再次触发回声；普通箭也能触发，所以弹药耗尽仍有构筑效果。整轮24箭已满时改为每阶12基础追击，随箭伤系数增长，不突破箭数上限。

**元素引信**：每轮一次，在特殊箭命中时额外引爆目标已有火毒伤害。一至三阶为当前一轮持续伤害的60%／90%／120%；不提前消耗持续回合、不重复附加状态。已有火或毒时才会进入候选，避免无效卡。

**神射回收**：每关特殊箭爆头可回收1份弹药，最多一次、最高一阶。破阵的掩体回收和神射的精准回收分别计数，都受5份容量限制，不能靠多箭反复刷弹。

这些触发只属于无尽玩家。NPC即使带有同名测试属性，也不会获得追击、引信或回收；单轮多箭、暴击、元素及随后持续伤害仍共用原预算。回声、引信、回收都有局部视觉反馈，不额外增加震动。

## 状态与验证

弹药、回收次数和追击标记均为局内临时状态，沿用v2永久存档与云存档格式，不新增后端资源。真实伤害、击破和弹药扣除后才触发收益，预瞄和强化预览不改变随机数、生命或奖励。

检查覆盖取消不扣弹、多箭仅扣一份、补弹不重复、隔关强化与选路、守关休息、结算重复点击、追击不递归、24箭补偿、引信状态结算、两类回收上限、NPC预算和实际手机DOM操作。中后期实战基准使用隔关节奏实际可获得的强化次数，而非旧的每关奖励构筑。原生Canvas出图和DOM适配检查不等于真实浏览器或手机GPU验收。
