# 当前游戏设计与实现

独立绘制的中文像素弓箭游戏，原生 Canvas / JavaScript，无依赖、无模型调用。入口为 `dist/index.html`；`dist/download.html` 是内联全部资源的单文件离线版。

## 玩法

- 三章剧情：青岚古道（近距离练习）、赤砂关隘（远距离、多障碍）、星坠遗迹（每次交锋后生成道具）。所有关卡刚开始都没有道具球，前两章始终不生成。
- 完成第三章后解锁无尽远征、自由人机、同机双人和百步穿杨。主线检查点、解锁状态、远征最高层、射靶最高分、余烬和永久修行保存在当前浏览器。
- 左侧青松与右侧赤岩轮流行动。每回合先看对方，再回到当前弓手；观察时禁止误射，空格可跳过。
- 拖拽拉弓，松手射箭；拉回可见取消圈、右键、Esc 均可取消。失去焦点、系统取消指针也会取消蓄力。左右键微调整数角度，空格射箭。
- 木箱两击破碎，木桩一击倾倒。穿过一个 `+1` 球增加一支箭，可连续叠加为 1→2→3→4；一轮最多 24 支箭。爱心回复射手生命。全部箭结束后才切换回合。
- 三章分别有行进、拦路箭、打开关隘、星灯苏醒等镜头。最终通关点亮星灯；普通胜利和失败有不同角色动作。

## 无尽远征

先选择逐风弓、落星弓或焰灯弓。射出箭后，在飞行途中再按空格、点击画面或弓术按钮，每轮可触发一次：

- 散羽：每支飞箭分成三支，各造成 60% 直接伤害。
- 星坠：向下俯冲，直接伤害提高 25%，额外穿过一个障碍。
- 引爆：消耗飞箭，在附近造成范围伤害，并损伤掩体。

分裂箭、道具追加箭和弓术继承已获得的元素。赢一层从三件遗物中选一件，携带生命与强化进入下一层。提供 12 类遗物：伤害、多箭、火、冰、毒、穿透、吸血、护甲、回春、暴击、生命、爱心强化。

有五种组合：火冰融爆、火毒毒焰、毒吸血腐生、冰穿透霜裂、护甲回春坚守。新遗物能组成搭配时会显示提示，选项也会提供已持有属性的搭档。敌人随层数增强，每三层有守关者；第四层后出现带毒或火的敌人。守关后额外回复生命。胜利获得余烬，可在旅营永久提升远征初始伤害与生命。永久升级不影响主线和同机双人公平性。

## 百步穿杨

射击上下浮动的普通靶和金靶，连续命中提高得分；每组三靶清空后换新，三次落空后结算。没有电脑回合和道具球，最高分保存在本机。

## 实现与规则

- `dist/core.mjs`：纯游戏状态、抛物线、碰撞、电脑瞄准、状态效果、技能、升级和存档验证。
- `dist/render.mjs`：地图、角色、镜头、场景动画与粒子。
- `dist/app.mjs`：输入、界面、音效与本地存储。
- `dist/style.css`：响应式界面；`dist/index.html`：页面结构。
- 世界为 1600×900；第一章双方间距 840，远距离地图间距 1360。角度 5°–75°，显示与控制均取整数。
- 部位基础伤害：头 42、身体 26、腿 18、脚 12。默认生命 100。电脑扫描真实弹道的可命中角度，再从扩大的整数区间随机取值，早期主线留有更大误差。
- 浏览器存档仅保留进度、纪录和永久修行；离开当前远征会结束本次临时构筑。无账号、跨设备同步或在线匹配。

## 参考与取舍

本次调研了 Bowmasters 的官方商店介绍、武器分类攻略、角色社区资料和模式攻略。参考机制并独立设计角色、美术、剧情和数值：

- [官方 Google Play](https://play.google.com/store/apps/details?id=com.playgendary.bowmasters)：多武器、对决、猎鸟和射果实等模式。这里采用通关解锁的射靶挑战。
- [官方 App Store](https://apps.apple.com/us/app/bowmasters-multiplayer-games/id1118431695)：角色、武器与活动模式概览。
- [Gamezebo 武器与角色攻略](https://www.gamezebo.com/walkthroughs/how-to-pick-the-right-character-in-bowmasters/)：直线、旋转和特殊投射物，以及飞行中二次触发。这里发展为三种弓术。
- [Gamezebo 模式攻略](https://www.gamezebo.com/walkthroughs/bowmasters-tips-cheats-and-strategies/)：不同技巧挑战与逐步解锁。旧攻略中的具体解锁次数不作为当前版本事实。
- [Thor 社区条目](https://bowmasters.fandom.com/wiki/Thor)、[Ron Etienne](https://bowmasters.fandom.com/wiki/Ron_Etienne)、[Ice Lord](https://bowmasters.fandom.com/wiki/Ice_Lord)：俯冲、分裂类技能的历史社区描述，仅作为玩法灵感。

## 验证边界

开源基线已做游戏逻辑、输入事件与真实 Canvas 渲染检查。已有 Node 测试不代表真实浏览器点击验收。后续改变交互或布局时应补做浏览器验证，并记录环境限制。

公开仓库保留可移植的 Node 逻辑测试；不依赖原开发环境的绝对路径和私有工具。
