# 当前游戏设计与实现

独立绘制的中文像素弓箭游戏，原生 Canvas / JavaScript，无依赖、无模型调用。入口为 `dist/index.html`；`dist/download.html` 是内联全部资源的单文件离线版。

## 玩法

- 三章剧情：青岚古道（近距离练习）、赤砂关隘（远距离、多障碍）、星坠遗迹（每次交锋后生成道具）。所有关卡刚开始都没有道具球，前两章始终不生成。
- 完成第三章或主动跳过新手教程后解锁无尽远征、自由人机、同机双人和百步穿杨。主线检查点、解锁状态、远征最高层、射靶最高分、余烬和永久修行保存在当前浏览器。
- 左侧青松与右侧赤岩轮流行动。玩家回合先看对方，再回到当前弓手；观察时禁止误射，空格可跳过。电脑对手在伤害、状态与回春结算后立即射箭，不做观察或思考等待；同机双人保留每位玩家的观察镜头。
- 瞄准时短点画面交替播放跳跃（0.85秒）或秀肌肉（1.2秒）。动作只修改渲染姿势，不改变物理位置、碰撞、瞄准和随机序列；拉弓、射箭或回合变化立即恢复动作。长按、系统取消和拉回取消圈不触发小动作；远征飞行中点击仍优先施展弓术。
- 拖拽拉弓，松手射箭；拉回可见取消圈、右键、Esc 均可取消。失去焦点、系统取消指针也会取消蓄力。左右键微调整数角度，空格射箭。
- 木箱两击破碎，木桩一击倾倒。穿过一个 `+1` 球增加一支箭，可连续叠加为 1→2→3→4；一轮最多 24 支箭。爱心回复射手生命。全部箭结束后才切换回合。
- 三章分别有行进、拦路箭、打开关隘、星灯苏醒等镜头。最终通关点亮星灯；普通胜利和失败有不同角色动作。

## 无尽远征

先选择逐风弓、落星弓或焰灯弓。射出箭后，在飞行途中再按空格、点击画面或弓术按钮，每轮可触发一次：

- 散羽：每支飞箭分成三支，各造成 60% 直接伤害。
- 星坠：向下俯冲，直接伤害提高 25%，额外穿过一个障碍。
- 引爆：消耗飞箭，在附近造成范围伤害，并损伤掩体。

分裂箭、道具追加箭和弓术继承已获得的元素。火、毒每次命中按天赋阶数追加对应状态层数，连续命中继续累加并刷新持续时间：火每层每轮 5 点、持续两轮；毒每层每轮 3 点、持续三轮，目标同时灼烧时毒提高为每层 5 点。旧版火 4 层／毒 5 层的小上限已移除；仅保留天赋 999 阶、状态 9999 层的安全上限。冰霜满 3 阶后不再提供，旧高阶数值保持兼容。升级卡提供实际前后收益，HUD 显示层数与剩余回合，暂停页展示基础持续伤害。赢一层从三件遗物中选一件，携带生命与强化进入下一层。提供 12 类遗物：伤害、多箭、火、冰、毒、穿透、吸血、护甲、回春、暴击、生命、爱心强化。

有五种组合：火冰融爆、火毒毒焰、毒吸血腐生、冰穿透霜裂、护甲回春坚守。新遗物能组成搭配时会显示提示，选项也会提供已持有属性的搭档。敌人随层数增强，每三层有守关者；第四层后出现带毒或火的敌人。守关后额外回复生命。胜利获得余烬，可在旅营永久提升远征初始伤害与生命。永久升级不影响主线和同机双人公平性。

## 百步穿杨

射击上下浮动的普通靶和金靶，连续命中提高得分；每组三靶清空后换新，三次落空后结算。没有电脑回合和道具球，最高分保存在本机。

## NPC 与反击空间

- 主线第一至三章：NPC 直接伤害倍率为 0.60 / 0.65 / 0.70，单轮总伤害上限为 24 / 28 / 30。预算包含追加箭、暴击、元素组合以及紧随其后的持续伤害，在 NPC 下一次发射时刷新。
- NPC 同轮第二次及之后爆头的基础伤害乘 0.45；穿 +1 后的追加箭采用更大散射。玩家的追加箭与同机双人保留完整伤害。
- AI 扫描可命中的整数角度，优先考虑身体和四肢。低抛只能打头时，也会考虑高抛；低抛误差为 ±9° / ±7° / ±6°，高抛窗口较窄，误差最多 ±2°。先清障碍和寻找道具仍会改变战局。
- 远征前六层保留原强度：血量每层增加 16，每三层守关者额外增加 30。第七层起令 `depth=max(0,层数−6)`，普通敌人额外生命 `6×depth²`，守关者 `8×depth²` 并再加 `5×depth`，匹配可持续叠加的火毒构筑。
- 深层敌人分为火毒穿透、冰甲回春、火毒冰与吸血等组合。守关者第十二层起三箭、第二十四层起四箭；一些后期敌人在承受本轮持续伤害后净化剩余火毒层数的 25%，不会免疫或提前抹掉当轮伤害。能力在观察阶段和暂停详情展示。
- 远征 NPC 单轮预算从 26 上升；100 最大生命的玩家仍最多承受 42。深层预算随玩家额外生命温和增加，始终不超过最大生命的 42%；前期与主线不受此成长影响。

## 角色与受击

- 旅营和暂停菜单可给两位弓手设置最多8个字符的显示名字；留空使用青松/赤岩。名字用于HUD、剧情说话人/台词、回合提示和结算，不改变角色ID、技能、血量或关卡状态。保存后写入可选的v2存档names字段；旧存档不受影响，取消设置不落盘。

- `CHARACTERS` 定义已有青松、赤岩。`skills.initial` 是角色天赋，`skills.weapon` 是选择的弓术，`skills.extra` 是本次远征所得遗物；后者不覆盖初始技能。
- 当前两名弓手都有「沉着」：每场首次在自己的回合生命不高于 35% 时，回复 10 点生命；每场一次。天赋每个遭遇刷新，遗物按远征保留，重开清除临时强化。新增角色流程见 [角色扩展说明](CHARACTERS.md)。
- 头、胸、髋与四肢使用 11 个关节点和长度约束；冲量按命中位置传到不同关节。重击可后仰、翻倒，腿脚命中先失衡。角色可沿地形移动，距初始站位最多 85 个世界单位。
- 动作期间命中区域跟随关节，插箭跟随所中骨段。存活角色约 1.25～2.1 秒起身；全部箭与起身完成后切换回合。死亡后保留落地姿势并停止持续模拟，避免抖动。

## 新手节奏与进度迁移

- 第一章对手从 50/100 生命开始；玩家仍为 100，第二、三章与其他模式不受影响。
- 第一章剧情每幕 2.5 秒、观察镜头 1.5 秒；台词立即完整显示。首页「跳过新手教程，解锁全部玩法」和首次剧情的跳过按钮会返回旅营、永久解锁其他模式；不增加余烬、纪录或修行，也不修改已到达的主线检查点。已解锁后，剧情中的跳过仅略过当前演出进入观察。电脑和手机都能主动跳过观察。
- 剧情台词和结局内容本次未改写。未来改为幽默风格时，需把倒地表现与战后对话一起调整。
- 旅营／暂停菜单可以导出永久进度代码，导入仅允许在旅营。不同网站以较高章节、解锁、纪录、余烬和永久修行为准合并，不自动同步或搬运本局远征属性。发布入口见 [部署说明](DEPLOYMENT.md)。

## 手机操作

- 一个网址提供「自动识别 / 电脑版 / 手机版」。手动选择优先于设备检测；选回自动后继续随窗口调整。电脑选择手机版时显示居中的竖屏布局。
- 切换仅改变显示和按钮，不重开对局、不清空进度；正在拉弓时先取消，飞行中的箭继续飞行。显示选择单独保存在 `hillside-archers-view-v1`，不改游戏存档。
- 竖屏使用跟随镜头；横屏能看到更宽的地形。画布按屏幕比例重绘，不拉伸角色。
- 手指按住画面向身后拉弓，松开发射；回到取消圈或点取消按钮撤销。触屏取消范围至少 32 CSS 像素。
- 提供整数角度加减、射箭、跳过观察镜头和弓术按钮；不需要键盘。
- 旋转、窗口变化、系统指针取消或切到后台时取消正在进行的拉弓；第二根手指不会接管射击。
- 不支持原生全屏时可切换页面沉浸模式。菜单可滚动，支持刘海和底部手势安全区。

## 实现与规则

- `dist/core.mjs`：纯游戏状态、抛物线、碰撞、电脑瞄准、状态效果、技能、升级和存档验证。
- `dist/combat.mjs`：NPC 强度预算与角色初始天赋。
- `dist/body.mjs`：受击冲量、关节、地面接触、恢复与插箭附着。
- `dist/render.mjs`：地图、角色、镜头、场景动画与粒子。
- `dist/app.mjs`：界面、屏幕适配、音效与本地存储。
- `dist/input.mjs`：鼠标、触屏与蓄力取消。
- `dist/display.mjs`：布局选择、设备检测与显示偏好存储。
- `dist/save-transfer.mjs`：永久进度代码校验与合并；非ASCII名字使用JSON转义，保持HA2兼容。
- `dist/names.mjs`：名字校验、默认值与剧情文本替换。
- `dist/mobile.css`：触屏按钮、安全区和横竖屏布局。
- `dist/style.css`：响应式界面；`dist/index.html`：页面结构。
- 世界为 1600×900；第一章双方间距 840，远距离地图间距 1360。角度 5°–75°，显示与控制均取整数。
- 部位基础伤害：头 42、身体 26、手臂 22、腿 18、脚 12。默认生命 100。NPC 额外应用上述倍率与伤害预算。
- 浏览器存档仅保留进度、纪录和永久修行；离开当前远征会结束本次临时构筑。无账号、跨设备同步或在线匹配。

## 参考与取舍

本次调研了 Bowmasters 的官方商店介绍、武器分类攻略、角色社区资料和模式攻略。参考机制并独立设计角色、美术、剧情和数值：

- [官方 Google Play](https://play.google.com/store/apps/details?id=com.playgendary.bowmasters)：多武器、对决、猎鸟和射果实等模式。这里采用通关解锁的射靶挑战。
- [官方 App Store](https://apps.apple.com/us/app/bowmasters-multiplayer-games/id1118431695)：角色、武器与活动模式概览。
- [Gamezebo 武器与角色攻略](https://www.gamezebo.com/walkthroughs/how-to-pick-the-right-character-in-bowmasters/)：直线、旋转和特殊投射物，以及飞行中二次触发。这里发展为三种弓术。
- [Gamezebo 模式攻略](https://www.gamezebo.com/walkthroughs/bowmasters-tips-cheats-and-strategies/)：不同技巧挑战与逐步解锁。旧攻略中的具体解锁次数不作为当前版本事实。
- [Thor 社区条目](https://bowmasters.fandom.com/wiki/Thor)、[Ron Etienne](https://bowmasters.fandom.com/wiki/Ron_Etienne)、[Ice Lord](https://bowmasters.fandom.com/wiki/Ice_Lord)：俯冲、分裂类技能的历史社区描述，仅作为玩法灵感。

## 验证边界

开源基线已做游戏逻辑、输入事件与真实 Canvas 渲染检查。已有 Node 测试不代表真实浏览器点击验收。后续改变交互或布局时应补做浏览器验证，并记录环境限制。

公开仓库保留可移植的 Node 逻辑测试；不依赖原开发环境的绝对路径和私有工具。
