# 0.19.0 随机站距、近预瞄与成就商店

## 箭更利落，瞄准留给玩家

电脑回合的飞行模拟以1.7倍播放，箭速／重力公式、AI误差与单轮伤害预算保持原值；不会通过提高NPC伤害来制造“快”。玩家飞行、双人和射靶速度保持原样，星坠预瞄仍为三分之一时间。

教程首战保留固定站位。其他新局使用带种子的安全站位变化，十二张地图仍保留作者设计的坡形与掩体；脚下坡度、掩体间距、双方距离和弹道都经过检查。新局或重开可变化，重复setup不重新抽取；无尽路线预览与真正开场使用同一份站位，随机后仍保证两条路线有明显距离或高差区别。实际初始间距约430–1540，地图两侧退让空间保留。

普通蓄力预瞄最多6个点、144世界单位，并限制为当前视野宽度的28%；拉满也不会铺到对手身上。星坠是在空中主动使用的独立预瞄，保留完整落线。

普通箭／特箭选择和技能操作一起放到左下角。选择不扣弹，射出普通箭后本轮不会临时变成特殊箭；选择特箭后仍在飞行中按按钮或空格施展，星坠按住预瞄、松开执行。默认沿用特箭准备，有弹药时可改选普通箭；空弹药自动作为普通箭发射。

单触依次播放转弓接弓、低身残影和举弓划空，带局部墨线、弧光与残影。动作不改变真实站位、碰撞、角度、伤害或随机数，真正拉弓立即恢复操作。系统减少动态时使用短静态致意，不追加屏幕震动。

## 作者练习码

旅营 → 成就与商店 → 作者练习码：`SHENG-ARCHER-2026`。

这是公开的调试入口，不是私密管理员口令。开启后使用独立的内存练习副本，解锁模式、全部装束／天赋和测试风格券，可反复试弓术；画面会标记“作者练习”。正式存档、成就、纪录、余烬和云余额保持原样。只可在旅营退出，退出恢复正式档；关闭页面后也回到正式档。

云同步与迁移导出读取正式档，练习中禁止导入正式进度。即使正式云同步请求在练习期间返回，也只更新被保留的正式副本，不会上传测试奖励。个人存档服务本身不承担竞技排行榜反作弊，源码可见的调试码也不提供服务端管理权限。

## 存档与验证

沿用v2存档与HA2迁移码，新增可选collection对象。云端冲突选择完整的钱包／商品快照；迁移码采用较高collection修订号，同号保留本机，不取最大余额加已购物品并集。旧客户端没有collection字段时，服务器保留原收藏。

浏览器保留旧版同步记录时，开场补领纪录成就不会覆盖云端已购物品；在旅营先接回完整云端收藏，再补领尚未领取的纪录奖励。两边都有实质收藏变化时保留人工选择；旧的待发送请求仍用原资料、版本号和请求ID重试。

已在原CloudBase上海环境应用版本化SQL迁移；事务测试使用两个临时身份并回滚，验证格式、账号隔离、请求去重、修订冲突和旧字段保留，随后复核实际权限。未改写已有玩家存档，也未新建环境或升级套餐。

自动检查覆盖随机实际弹道、NPC飞行时间与预算、选择箭型、动作／皮肤纯渲染、购买／装备、成就幂等、练习隔离和迁移／云协议。原生Canvas检查电脑／手机／受击／商店头像29个画面；没有真实浏览器控制工具，未验收手机GPU帧率或完整浏览器布局。
