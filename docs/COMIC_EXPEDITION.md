# 荒诞漫画竞技：当前版本与下一步创意

0.14.0 的方向是「严肃地瞄准，离谱地收场」。保留弓箭的落点博弈，用场地、对手意图和局部反馈建立变化。不是通过无限加血、暴增粒子或同时加入一堆弹道规则制造热闹。

## 已经做进游戏

- 青蓝／珊瑚红运动配色，粗墨线、夸张眉眼、露齿表情、大靴子和号码布；保留原来的关节受力与移动部位碰撞。
- 主页与升级页改为暖纸色比赛海报；短标题使用得意黑，血量数字使用 Barlow Condensed，正文保留清楚的系统中文字体。字体随站点与离线包提供，不请求海外字体 CDN。完整字体许可位于 `dist/fonts/`。
- 命中漫画星芒与「啪／好头」拟声字、出箭、木屑和落地尘；移除覆盖新实现的旧 `particles` 方法。普通命中和爆头分别反馈，一轮多箭只由更强的一击升级镜头冲击。
- 暂停菜单中「画面震动：轻／标准／关」。默认轻；系统减少动态效果优先。冲击以屏幕 CSS 像素计量，约 0.12–0.16 秒衰减，不叠加多箭，不震动网页 HUD。高抛／命中跟随与震动分别计算。
- 无尽胜利后，在原升级页先选下一场路线（已有默认），再点遗物直接继续；预告具体赛场、敌人打法、补给倾向。没有多加一页确认。
- 场地／首领／敌人打法分别安排；首领不再固定落到第三张图。相同种子可重现路线，预览和绘图不消耗战斗随机数。路线是本次远征的临时状态，不改 v2 存档或云存档格式。
- 四种真实打法：认真打工人偏低弧身体；高抛怪尝试高弧身体；拆台客会破坏阻挡射线的掩体；追心鬼受伤后会瞄准可到达的爱心。都保留原瞄准误差、NPC 单轮伤害预算和多箭爆头衰减。

## 最值得继续试的创意（以下尚未实现）

| 优先 | 方向 | 一场里能看到什么 | 博弈与边界 |
| --- | --- | --- | --- |
| 1 | 有脾气的角色与专属投射物 | 快递员射包裹：空中拆成三份；厨子射煎锅：手动翻面落下；摄影师射闪光灯：命中留下标记 | 首先做 3 个角色，每人一个清晰初始技能、两条肉鸽强化分支；先靠手感差异，不堆基础伤害 |
| 2 | 观众悬赏 | 「这场先拆两箱」「穿过两个 +1」「用脚部命中收尾」 | 赛前公开，完成给小额回血或一次重选；不完成也可正常过关，不强迫拖长战斗 |
| 3 | 规则会变的首领 | 裁判骑着收费亭登场；第 3／5 回合路障倾倒、爱心补给换边；首领先举牌展示意图 | 给足一回合预告，让玩家能抢补给或拆掩体；机关伤害也必须算入 NPC 预算 |
| 4 | 把组合变成画面事件 | 毒火箭命中后喷出绿色火舌；冰穿透打碎掩体时产生定向冰屑；吸血毒回流一条细藤 | 先显示现有真实组合，再为每种组合试一个可控副效果；限制粒子、避免整屏闪光 |
| 5 | 好笑的常客与恩怨 | 被打飞的码头工下一次戴头盔回来；嘴硬的裁判结算举反牌；重复遇到同一人会换一句台词 | 使用固定角色事件与短动作，不需要生成式 AI、配音服务或联网；两秒内可跳过 |
| 6 | 每日路线码／好友挑战 | 同一地图种子、同样的路线与遗物池，比谁用更少箭通关 | 可先做无账号的分享码。排行和防作弊是后续独立工作；仅固定地图还不等于完整公平种子赛 |

建议顺序：**专属投射物 → 悬赏 → 两个带预告机关的首领**。这三项最能增加新鲜感，且能复用现有整数弹道、二段技能和掩体系统。风、反弹、移动平台、双敌人同时出场会同时改变大量碰撞与瞄准判断，建议各自做一个独立试验关再决定。

## 参考与验证

Bowmasters 的参考价值主要是角色剪影、武器差异、飞行中触发和有分段的受击动作；不是照搬其角色或素材。相关官方与历史攻略见 [游戏设计](GAME_DESIGN.md#参考与取舍)。字体和反馈的额外资料见 [视觉研究](VISUAL_REFERENCES.md)。

本版运行规则、升级、NPC 公平性、输入、账号与存档、离线交互、路线和真实弹道测试；使用原生 Canvas 导出 8 张场地、角色与命中帧检查画面。渲染检查涵盖随机数与游戏状态不变、地形缓存更新、多箭反馈与暂停。当前环境缺可调用浏览器控制工具，DOM 适配器和 Canvas 图像不等于真实浏览器／手机帧率验收。
