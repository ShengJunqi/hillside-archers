# 0.20.0 游戏界面与暂停菜单

这次先对照六款游戏的商店截图、开发者资料及暂停界面，再决定改动。让地形、角色和飞箭成为主体，常用操作容易找到，详细资料在暂停时展开。

## 实际改动

- 右上角“Ⅱ 暂停”有底板、描边、阴影与按压反馈。电脑58×62、手机48×54 CSS像素，血条右侧预留空间；保留Esc。
- 暂停分“本局／设置／操作”。“继续对决”始终是主操作；重开和返营分别说明会重置或结束当前对局。
- 本局页显示地图、站距类别、双方生命和最多五种遗物摘要；完整遗物、对手能力与异常状态折叠阅读。
- 声音、震动、镜头、全屏、风景、显示布局集中到设置。旅营也能打开设置，隐藏不适用的对局操作。
- 手机竖屏生命信息在上排，章节另占一条；横屏恢复三列。长名字省略，异常摘要限行，暂停保留完整资料。
- 旅营模式与小工具改为成组游戏按钮；账号、改名、迁移窗口统一纸色、漫画字体和输入对比，沿用得意黑与Barlow字体。
- 箭型选择保留左下角；不更改弹药、回合、站位、随机种子或存档规则。

## 交互约定与验证

暂停先取消蓄力或星坠预瞄，再冻结游戏更新；迟到的指针／空格松开不能射箭或扣弹。恢复后继续同一支在飞箭，键盘焦点回到游戏画布。

Tab只在当前页和主操作之间循环，方向键切换页签，Esc先关闭布局选择，再关闭暂停。子窗口关闭后回到暂停中的实际入口。风景页的主按钮保留直接返回游戏的行为，同时关闭暂停层。

cloud-ui.mjs只新增可选returnFocus回调，使旅营设置的账号窗口返回正确按钮；未更改认证、云存档协议或数据库。

新增tests/interface.test.mjs解析发布HTML的节点层级，用实际游戏与应用模块检查隐藏祖先、焦点、页签、迟到松手、飞箭冻结／恢复、布局切换和多层窗口。覆盖320、390、844、1280宽度的模式与事件路径。这是DOM适配器，不计算CSS布局。

interface.css作为最后一层样式发布，离线版同样内联。现有输入、手机、弹药、商店、账号及游戏测试继续运行。

当前没有可用浏览器控制入口，按Sites工作流跳过浏览器QA，未安装或绕过使用其他浏览器控制方式。真实像素布局、滚动手感与手机GPU表现仍待实测；DOM检查不等于实机验收。
